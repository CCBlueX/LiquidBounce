# Train Data Collector Schema Specification

This document describes the schema for the Parquet files generated by `ModuleTrainDataCollector`. 
The files contain data points collected every Minecraft tick (20Hz) for machine learning purposes.

## File Format
- **Format:** Parquet
- **Compression:** ZSTD

## Schema

Each row in the Parquet file represents a single frame (tick) for one specific player in the game.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `timestamp` | `long` | Timestamp of the frame. Calculated as `session_start_seconds + ticks_since_start`. |
| `playerId` | `string` | The UUID of the player. |
| `posX` | `double` | Absolute X coordinate of the player. |
| `posY` | `double` | Absolute Y coordinate of the player. |
| `posZ` | `double` | Absolute Z coordinate of the player. |
| `yaw` | `float` | Player's look yaw, represented in **radians**. |
| `pitch` | `float` | Player's look pitch, represented in **radians**. |
| `isSneaking` | `boolean` | `true` if the player is sneaking. |
| `isOnGround` | `boolean` | `true` if the player is standing on the ground. |
| `isUsingItem` | `boolean` | `true` if the player is actively using an item (e.g. eating, blocking, drawing a bow). |
| `isSwinging` | `boolean` | `true` if the player performed an arm swing (attack/mine) in this frame. |
| `wasHit` | `boolean` | `true` if the player took damage in this frame. |
| `closestArrowX` | `double` | X position of the closest flying projectile, **relative** to the player's position. |
| `closestArrowY` | `double` | Y position of the closest flying projectile, **relative** to the player's position. |
| `closestArrowZ` | `double` | Z position of the closest flying projectile, **relative** to the player's position. |
| `mainHandCategory` | `int` | Integer representing the category of the item held in the main hand. |
| `offHandCategory` | `int` | Integer representing the category of the item held in the off-hand. |
| `floorMap` | `int[]` | Array of 225 integers (15x15 grid) containing floor height distances. Scaled as 16-bit fixed point: `actual_distance * 256.0`. Cast a ray from `player.y + 1.5` down to `player.y - 10.0`. Missing hits default to `-10.0`. |
| `ceilMap` | `int[]` | Array of 225 integers (15x15 grid) containing ceiling height distances. Scaled as 16-bit fixed point: `actual_distance * 256.0`. Cast a ray from `player.eyeHeight` up to `player.eyeHeight + 4.0`. Missing hits default to `4.0`. |
| `poiMap` | `int[]` | Array of 225 integers (15x15 grid) representing the highest priority POI type in a `y - 3` to `y + 3` column. |

### Map Coordinate System
The 15x15 arrays (`floorMap`, `ceilMap`, `poiMap`) are extracted relative to the player's `yaw`, so the arrays mathematically "rotate" with the player. 
The mapping iterates from `Z: -7 to +7` (outer loop) and `X: -7 to +7` (inner loop).
